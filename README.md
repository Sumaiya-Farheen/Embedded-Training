# Embedded-Training
Embedded Systems Training provided hands-on experience in microcontrollers, sensors, actuators, and hardware-software integration. During my Embedded Systems Training, I completed several mini-projects that provided hands-on experience with microcontrollers, sensors, actuators, and hardware-software integration. These included a "soil moisture monitoring system"to detect soil moisture levels, displaying "DHT11 temperature and humidity readings on a TFT display", and monitoring DHT11 sensor data through a web dashboard. I also gained practical knowledge of communication protocols such as "UART" and learned about sensor interfacing, circuit connections, embedded C programming, and real-time data monitoring. This training strengthened my practical skills in embedded system development and helped me understand their real-world applications.
